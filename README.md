Это ООП версия игры Супер Марио, которая:
1. Делает логику независимой от визуального представления.
2. Делает логику независимой от ОС.
3. Логика работает не с множествами объектов, а с множествами абстракций.
  
## Сборка

- По умолчанию проект собирает консольную версию (без зависимостей от Qt).
- Для Qt-интерфейса включите флаг `-DBUILD_QT_UI=ON` и передайте `CMAKE_PREFIX_PATH` до установленного Qt (см. `build.bat` для примера под Windows).
